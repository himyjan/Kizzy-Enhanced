<h3>Funktionen</h3>
<ul>
<li>Klickbare Buttons</li>
<li>Erkennt aktuell laufende App</li>
<li>Erkennt gerade gespielte Medien</li>
<li>Optionale Zeitstempel</li>
<li>Benutzerdefinierter Status</li>
<li>RPC-Konfigurationen speichern/laden</li>
<li>Material You Design</li>
<li>Übersetzungen</li>
<li>Einfache Einrichtung</li>
<li>Console RPC</li>
<li>Benutzerdefinierte RPC-Konfigurationen</li>
<li>RPC-Vorschau in der App</li>
<li>Läuft im Hintergrund</li>
<li>GIF-Unterstützung</li>
<li>Externe URL-Unterstützung</li>
<li>Bilder aus der Galerie</li>
<li>⭐ Plattform-Spoofing</li>
